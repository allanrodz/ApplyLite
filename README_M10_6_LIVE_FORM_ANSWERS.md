# M10.6 live-form answers

ApplyLite 0.14.7 extends M4.1 from static package screening drafts to questions discovered on the actual employer form.

For example, a form containing `What exceptional work have you done?` and `What makes you the ideal candidate for this position?` can now be drafted from verified candidate evidence after the browser opens. Questions about visa sponsorship, compensation, demographics, previous employment with the company, or missing social-profile URLs are not guessed.

The final employer submission remains manual.
